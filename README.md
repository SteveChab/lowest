# Lowest Hallowed

The website for [Lowest Hallowed](https://lowesthallowed.com): Christian dark ambient and dungeon synth for prayer, with unblack undertones. A new album comes out each month.

The site invites listeners into the Prayer Watch, a monthly gathering the night before each release, where many people pray separately at the same time. Prayers and requests go in the chat.

- Music: [Bandcamp](https://lowesthallowed.bandcamp.com) and [YouTube](https://www.youtube.com/@lowesthallowed)
- Site: plain HTML, CSS and JS, hosted on GitHub Pages
